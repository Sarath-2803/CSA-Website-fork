# My Journey Into Cybersecurity

*A personal journey from learning Linux fundamentals to exploring practical cybersecurity.*

**By Sharon P Shajan, CS' 27**

# The Beginning: Learning Linux

My journey into cybersecurity started with learning the fundamentals of **Linux**.

Before diving into security concepts or hacking tools, I wanted to become comfortable working with the command line, navigating the filesystem, understanding permissions, managing files, and connecting to systems through SSH.

A useful resource for getting started with Linux is [Linux Journey](https://linuxjourney.com/).

# Learning Through OverTheWire Bandit

Once I had a basic understanding of Linux, I moved on to [OverTheWire Bandit](https://overthewire.org/wargames/bandit/).

Bandit helped me apply what I learned in a practical environment.

As I progressed through the levels, I became more familiar with:

* Linux commands
* File permissions
* Searching for information
* SSH
* Pipes
* Redirection

More importantly, it taught me how to approach problems, research unfamiliar concepts, and experiment until I found a solution.

# Building Cybersecurity Knowledge with TryHackMe

After gaining confidence with Linux and basic problem-solving, I moved on to [TryHackMe](https://tryhackme.com/) for more structured cybersecurity learning.

Through guided rooms and learning paths, I explored topics such as:

* Networking
* Web technologies
* Linux and Windows systems
* Enumeration
* General offensive security concepts

TryHackMe helped me connect the different areas of cybersecurity while continuing to practice in hands-on environments.

# Moving on to Hack The Box

After developing more confidence and proficiency with the fundamentals, I moved on to [Hack The Box](https://www.hackthebox.com/).

This was where I started focusing more on independent problem-solving.

Rather than following heavily guided exercises, I practiced on machines that required me to:

* Enumerate systems
* Identify potential vulnerabilities
* Research techniques
* Work through challenges independently

# Looking Back

My cybersecurity journey has followed a gradual progression:

**Linux Fundamentals → OverTheWire Bandit → TryHackMe → Hack The Box**

Each stage built upon the previous one.

Linux gave me the foundation, Bandit improved my problem-solving skills, TryHackMe introduced structured cybersecurity concepts, and Hack The Box gave me the opportunity to apply those skills in more challenging environments.

For me, the most important part of learning cybersecurity has been consistently practicing and understanding *why* something works rather than simply memorizing tools or commands.

My journey started with Linux, and each step after that helped me build the confidence to explore cybersecurity further.
